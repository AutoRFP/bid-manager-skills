# Setup

Follow `skills/autorfp-setup/SKILL.md` when this plugin is enabled.

The AutoRFP MCP is read-only. This plugin bundles APAC at `https://api.app.autorfp.ai/mcp`. For EU or US, use the registered AutoRFP.ai connector or `https://api.eu.autorfp.ai/mcp` / `https://api.us.autorfp.ai/mcp`. Approve `tags:read`, `projects:read`, and `content:read`.

If AutoRFP/autorfp-ai-plugin is already connected, keep one AutoRFP MCP enabled.
