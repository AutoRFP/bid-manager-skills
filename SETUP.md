# Setup

Follow `skills/autorfp-setup/SKILL.md` when this plugin is enabled.

The AutoRFP MCP is read-only. Default host is `api.autorfp.ai`. EU is `api.eu.autorfp.ai`. US is `api.us.autorfp.ai`. Approve `tags:read`, `projects:read`, and `content:read`.

If AutoRFP/autorfp-ai-plugin is already connected, keep one AutoRFP MCP enabled.
