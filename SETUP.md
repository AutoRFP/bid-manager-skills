# Setup

Follow `skills/autorfp-setup/SKILL.md` when this plugin is enabled.

The AutoRFP MCP is read-only. Pick the region that matches your AutoRFP.ai login: APAC `https://api.autorfp.ai/mcp`, EU `https://api.eu.autorfp.ai/mcp`, US `https://api.us.autorfp.ai/mcp`. Approve `tags:read`, `projects:read`, and `content:read`.

If AutoRFP/autorfp-ai-plugin is already connected, keep one AutoRFP MCP enabled.
